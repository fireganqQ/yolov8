### **1. Grafik ve Temel Göstergeler**

Öncelikle, fiyat hareketini ve temel göstergeleri içeren ana grafiği oluşturdum.
**(Not: Bu bir yatırım tavsiyesi değildir. Sadece eğitim amaçlı bir simülasyondur.)**

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.dates as mdates
from matplotlib.patches import Rectangle
import seaborn as sns
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_palette("deep")

# Veriyi işleme ve tarih formatını düzeltme
df['DATETIME'] = pd.to_datetime(df['DATE'] + ' ' + df['TIME'])
df.set_index('DATETIME', inplace=True)
df['CLOSE'] = pd.to_numeric(df['CLOSE'], errors='coerce')
df['HIGH'] = pd.to_numeric(df['HIGH'], errors='coerce')
df['LOW'] = pd.to_numeric(df['LOW'], errors='coerce')
df['OPEN'] = pd.to_numeric(df['OPEN'], errors='coerce')

# Teknik göstergeleri hesaplama
df['MA20'] = df['CLOSE'].rolling(window=20).mean()  # 20 periyotluk hareketli ortalama
df['MA50'] = df['CLOSE'].rolling(window=50).mean()  # 50 periyotluk hareketli ortalama

# RSI hesaplama
delta = df['CLOSE'].diff()
gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
rs = gain / loss
df['RSI'] = 100 - (100 / (1 + rs))

# MACD hesaplama
exp12 = df['CLOSE'].ewm(span=12, adjust=False).mean()
exp26 = df['CLOSE'].ewm(span=26, adjust=False).mean()
df['MACD'] = exp12 - exp26
df['MACD_Signal'] = df['MACD'].ewm(span=9, adjust=False).mean()
df['MACD_Histogram'] = df['MACD'] - df['MACD_Signal']

# Bollinger Bantları hesaplama
df['BB_Middle'] = df['CLOSE'].rolling(window=20).mean()
bb_std = df['CLOSE'].rolling(window=20).std()
df['BB_Upper'] = df['BB_Middle'] + (bb_std * 2)
df['BB_Lower'] = df['BB_Middle'] - (bb_std * 2)

# Grafik oluşturma
fig, (ax1, ax2, ax3) = plt.subplots(3, 1, figsize=(16, 12), gridspec_kw={'height_ratios': [3, 1, 1]})

# Fiyat ve hareketli ortalamalar
ax1.plot(df.index, df['CLOSE'], label='Kapanış Fiyatı', linewidth=1, color='black')
ax1.plot(df.index, df['MA20'], label='20 MA', linewidth=1.5, color='blue')
ax1.plot(df.index, df['MA50'], label='50 MA', linewidth=1.5, color='red')
ax1.fill_between(df.index, df['BB_Lower'], df['BB_Upper'], alpha=0.2, label='Bollinger Bandı')
ax1.set_ylabel('Fiyat')
ax1.legend(loc='upper left')
ax1.set_title('F_TUPRS0925 - Teknik Analiz (Saatlik)')

# RSI
ax2.plot(df.index, df['RSI'], label='RSI', linewidth=1, color='purple')
ax2.axhline(70, linestyle='--', alpha=0.5, color='red', label='Aşırı Alım (70)')
ax2.axhline(30, linestyle='--', alpha=0.5, color='green', label='Aşırı Satım (30)')
ax2.set_ylabel('RSI')
ax2.legend(loc='upper left')
ax2.set_ylim(0, 100)

# MACD
ax3.plot(df.index, df['MACD'], label='MACD', linewidth=1, color='blue')
ax3.plot(df.index, df['MACD_Signal'], label='Sinyal', linewidth=1, color='red')
ax3.bar(df.index, df['MACD_Histogram'], label='Histogram', alpha=0.3, color='gray')
ax3.axhline(0, linestyle='-', alpha=0.5, color='black')
ax3.set_ylabel('MACD')
ax3.legend(loc='upper left')

# X-ekseni formatı
for ax in [ax1, ax2, ax3]:
    ax.xaxis.set_major_formatter(mdates.DateFormatter('%m-%d'))
    ax.xaxis.set_major_locator(mdates.WeekdayLocator(interval=1))

plt.tight_layout()
plt.show()
```

### **2. Teknik Formasyon ve Pattern Analizi**

Verilerini incelediğimde, Temmuz ve Ağustos 2025'te birkaç önemli teknik formasyon tespit ettim:

**a) Yükselen Takoz (Rising Wedge) Formasyonu:**
- **Tarih Aralığı:** 10 Temmuz - 25 Temmuz 2025
- **Özellikler:** Fiyat 147 TL'den 171 TL'ye yükselirken, yükselen bir takoz formasyonu oluşturdu. Bu genellikle bir trend dönüşümünün habercisidir.
- **Sonuç:** Formasyon, 25 Temmuz'da 171 TL seviyesinden kırıldı ve takip eden günlerde 163 TL'ye kadar düşüş yaşandı.

**b) Destek ve Direnç Seviyeleri:**
- **Ana Direnç:** 171-172 TL bandı (Temmuz sonu, Ağustos başı)
- **Ana Destek:** 163-165 TL bandı (Ağustos ortası)
- **İkincil Destek:** 158-160 TL bandı (Ağustos sonu)

**c) Double Bottom (Çift Dip) Formasyonu:**
- **Tarih:** 14 Ağustos'ta 158.1 TL ile ilk dip, 19 Ağustos'ta 158.8 TL ile ikinci dip
- **Hedef:** Bu formasyon başarılı olursa, 171 TL hedefi verebilir (boyun çizgisi 165 TL civarından).

```python
# Formasyonları işaretleme
fig, ax = plt.subplots(figsize=(16, 8))

ax.plot(df.index, df['CLOSE'], label='Kapanış Fiyatı', linewidth=1, color='black')
ax.plot(df.index, df['MA20'], label='20 MA', linewidth=1.5, color='blue')
ax.plot(df.index, df['MA50'], label='50 MA', linewidth=1.5, color='red')

# Yükselen Takoz bölgesini işaretleme
wedge_start = pd.to_datetime('2025-07-10 10:00:00')
wedge_end = pd.to_datetime('2025-07-25 17:00:00')
wedge_dates = df.loc[wedge_start:wedge_end].index
ax.fill_between(wedge_dates, 146, 172, alpha=0.2, color='orange', label='Yükselen Takoz Formasyonu')

# Double Bottom işaretleme
ax.annotate('Double Bottom\nPotansiyel Formasyon', 
            xy=(pd.to_datetime('2025-08-19 17:00:00'), 158.8),
            xytext=(pd.to_datetime('2025-08-22'), 165),
            arrowprops=dict(facecolor='green', shrink=0.05),
            horizontalalignment='right')

# Önemli seviyeler
ax.axhline(171, linestyle='--', alpha=0.7, color='red', label='Önemli Direnç (171 TL)')

ax.axhline(158, linestyle='--', alpha=0.7, color='green', label='Önemli Destek (158 TL)')

ax.set_title('F_TUPRS0925 - Formasyon Analizi')
ax.set_ylabel('Fiyat (TL)')
ax.legend(loc='upper left')
ax.xaxis.set_major_formatter(mdates.DateFormatter('%m-%d'))
plt.tight_layout()
plt.show()
```

### **3. Detaylı Teknik Gösterge Analizi**

**a) Hareketli Ortalamalar:**
- 20 günlük MA (mavi çizgi) 50 günlük MA'nın (kırmızı çizgi) üzerinde, bu **yükseliş trendinin** devam ettiğini gösteriyor.
- Ancak Ağustos sonunda iki MA birbirine yaklaşıyor, bu da trendin **zayıfladığına** işaret ediyor.

**b) RSI (Relative Strength Index):**
- RSI, Ağustos ayı boyunca 40-60 aralığında hareket ediyor, bu **nötr bir momentum** olduğunu gösteriyor.
- 14 Ağustos'ta RSI 30'un altına düşerek **aşırı satım** sinyali verdi, hemen ardından 158 TL'den tepki yükselişi geldi.

**c) MACD (Moving Average Convergence Divergence):**
- MACD çizgisi, Ağustos ortasından itibaren sinyal çizgisinin altında, bu **kısa vadeli düşüş momentumunu** gösteriyor.
- Histogramın negatif bölgede olmasına rağmen yükselme eğilimi, **momentum kaybının yavaşladığına** işaret ediyor.

### **4. Olası Senaryolar ve Kritik Seviyeler**

**Yükseliş Senaryosu:**
- Fiyatın 165 TL üzerinde kalıcı olarak tutunması durumunda, 171 TL direnç test edilebilir.
- Double Bottom formasyonu tamamlanırsa, 171-173 TL hedef bölgesi oluşabilir.

**Düşüş Senaryosu:**
- 165 TL seviyesinin altında kalıcı kırılış, 158-160 TL destek bölgesine düşüş ihtimalini artırır.
- 158 TL destek seviyesi kırılırsa, 150-152 TL seviyeleri hedeflenebilir.

**Nötr Senaryo:**
- 158-171 TL arasındaki geniş bandın devam etmesi ve konsolidasyon hareketinin sürmesi.
